# Frontend Design

Use this skill when building or improving web UI, components, app screens, dashboards, interactive tools, or frontend flows.

## Design Direction

Start from the user's real workflow. Choose a clear visual direction that fits the product domain: dense and restrained for operational tools, expressive for games or creative apps, editorial for content experiences.

## Implementation Rules

- Build the usable experience first, not a marketing shell.
- Follow the existing design system, component library, spacing, colors, and icons when present.
- Use familiar controls: icon buttons for tools, segmented controls for modes, toggles for booleans, sliders or numeric inputs for numbers, tabs for views.
- Avoid nested cards, decorative clutter, generic gradients, and UI text that explains the obvious.
- Keep typography sized to the container. Prevent button, card, toolbar, and sidebar text from overflowing.
- Make responsive behavior intentional. Do not simply shrink a desktop layout until it breaks.

## Verification

Inspect the page in realistic desktop and mobile viewports when possible. Check alignment, text wrapping, keyboard focus, loading states, empty states, and error states.
